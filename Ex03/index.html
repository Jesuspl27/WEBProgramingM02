Introducción

La programación web permite crear páginas y aplicaciones que funcionan directamente en un navegador.

Para crear una página web normalmente utilizamos HTML, CSS y JavaScript.

HTML

HTML es el lenguaje utilizado para crear la estructura de una página web.

Ejemplo de HTML

<h1>Hola mundo</h1>
<p>Mi primera página web</p>

CSS

CSS permite modificar la apariencia de los elementos HTML, incluyendo colores, tamaños, fuentes y espacios.

Propiedades importantes

  • font-family
  • font-size
  • line-height
  • font-weight
  • color
  • background
